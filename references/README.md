# Reference artifact staging

Store locally acquired manuals, source archives, captures, and definition archives here only when their license permits it. Before use:

1. Record source identity and acquisition details in `docs/SOURCE_REGISTRY.md`.
2. Compute and record a SHA-256 hash.
3. Inspect source archives for license files and source headers.
4. Update `THIRD_PARTY_NOTICES.md` before copying any implementation code.
5. Add protocol or baseline citations to the appropriate evidence register.

The directory is ignored by default to avoid accidentally redistributing restricted material.
