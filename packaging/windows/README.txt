4L60 Diagnostics — Windows installation

1. Extract the entire ZIP.
2. Double-click Install.cmd.
3. Launch 4L60 Diagnostics from the Desktop or Start menu.

The application includes its own .NET runtime. It does not install .NET system-wide
and does not require administrator access.

Windows may show an Unknown Publisher warning until the release is code-signed.
Use only a package downloaded from the project's official release page and compare
its SHA-256 checksum with the checksum published beside the release.
